# BakalaoStudios DataStore

The shared data of your characters for the BakalaoStudios addons (**Alterao!!**, **Enfocao!!**...). Install it with
them (the CurseForge and Wago apps do it for you): each character you log in with saves its level, gold, items, mail,
professions, reputations, cooldowns and lockouts once, and every addon reads them from here.

It has no window of its own.

**For addon authors:** the global `BakalaoDataStore` is the API, documented at the top of `API.lua`.
